# 나의 픽셀 하우스

코드로 픽셀 아트를 그리는 Streamlit 집 시뮬레이터 첫 번째 프로토타입입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 조작
- WASD 또는 방향키: 이동
- 마우스 클릭: 물건 선택 및 상호작용
- E: 가까운 물건 사용
- R: 처음 위치로 이동

## GitHub / Streamlit Community Cloud
이 폴더의 파일을 GitHub 저장소에 올린 뒤 Streamlit Community Cloud에서 `app.py`를 메인 파일로 지정하세요.
